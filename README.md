# Cave Adventure

Unity와 C#으로 제작한 2D 액션 플랫폼 게임입니다. 스테이지를 탐험하고 적과 보스를 상대하며, 아이템을 획득해 새로운 능력을 사용할 수 있습니다.

[▶ 시연 영상 보기](https://www.youtube.com/watch?v=HSkwNEcKFtM)

## 개발 환경

- Unity 2021.3.32f1
- C#

## 주요 기능

- 이동, 점프, 대시와 근접 공격
- 아이템 획득을 통한 이단 점프, 마법 공격, 변신 능력 해금
- 일반 적과 중간·메인 보스 전투
- 튜토리얼과 두 개의 스테이지
- JSON 기반 슬롯별 저장·불러오기

## 실행 방법

Unity 2021.3.32f1에서 프로젝트를 열고, `Assets/4.Scenes/Main.unity` 씬에서 실행합니다.
